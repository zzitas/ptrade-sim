CHAPTER 01

源头——2017年，一本英文书与一个公式

1.1 这本书写了什么

2017年，安德烈亚斯·F.克列诺（Andreas F. Clenow）出版了《趋势永存：打败市场的动量策略》（Stocks on the Move）。克列诺是瑞士ACIES Asset Management AG的首席投资官，他在书中描述了一个在其基金公司运行了20多年的策略。

📚 参考文献：Clenow, A. F. (2017). Stocks on the Move: Beating the Market with Momentum. John Wiley & Sons.

策略的核心极其简单，克列诺自己总结为一句话："买入上涨的股票"。展开为完整的系统：

步骤 内容 理论依据
熊市过滤 标普500的200日均线判断熊市，熊市则空仓 趋势过滤器（Murphy, 1999）
个股筛选 剔除价格在100日均线下的股票；剔除过去90天存在15%以上价格缺口的股票 流动性与信号纯度过滤
动量计算 对价格序列做指数回归，用R²表示拟合程度，二者乘积作为分数给股票排名 动量因子（Jegadeesh & Titman, 1993）
仓位管理 引入ATR计算头寸规模 波动率标准化（Wilder, 1978）

第三点，是整个故事的起点。

1.2 那个公式，到底在算什么

公式极其简单：

score = annualized_return × R²

第一步：对数价格对时间的线性回归

y = np.log(close_prices)           # 对数价格
x = np.arange(len(y))              # 时间序列 [0, 1, 2, ...]
slope, intercept = np.polyfit(x, y, 1)  # 最小二乘

slope 代表每日对数收益率的平均值。年化后：

annualized = eslope × 250 − 1

第二步：计算R²

R² = 1 − Σ(yᵢ − ŷᵢ)² / Σ(yᵢ − ȳ)²

R²衡量的是线性模型对数据变异的解释比例。在金融语境中，它衡量的是"趋势的连续性"——价格是否沿一条直线稳步上升，而非暴涨暴跌。

第三步：相乘

score = annualized × R²

为什么要乘？

斜率单独不够。一只股票暴涨暴跌，年化收益率可能很高，但R²很低——说明趋势不连续。乘以R²相当于对"脉冲式上涨"降权，奖励"稳步上涨"的标的。

统计学本质：这个公式的经济含义是找到"趋势最稳定、且斜率最陡"的标的。它本质上是一个信号-噪声比（Signal-to-Noise Ratio）的代理变量。斜率（annualized return）是信号，R²是信号的纯度。

这个因子有一个重要的背书：它不是某个人拍脑袋想出来的，而是一家对冲基金运行了20多年的策略核心。不存在过拟合，不存在未来函数。

1.3 理论根基：动量因子的学术传统

克列诺的公式并非凭空创造，它有深厚的学术根基：

Jegadeesh & Titman (1993)：首次系统性记录了动量效应——过去3-12个月表现好的股票在未来3-12个月继续表现好。这是金融学最robust的经验规律之一。

Asness, Moskowitz & Pedersen (2013)：证明动量因子在全球多个资产类别（股票、债券、货币、商品）中都有效，是一个系统性的风险溢价。

Novy-Marx (2013)：发现"质量动量"（盈利质量高的股票动量效应更强），为动量因子提供了基本面支撑。

克列诺的公式之所以有效，是因为它在经典动量因子的基础上，加入了R²作为"趋势纯度"的度量——这等价于对动量信号做了一个夏普比标准化。

CHAPTER 02

第一次移植——wywy1995与4只ETF的轮动

2.1 为什么从股票换到ETF？

2019-2020年，聚宽用户开始尝试把克列诺的公式从股票移植到ETF。

为什么是ETF？因为ETF天然分散，没有个股黑天鹅。而且ETF之间的相关性可以事先控制，轮动起来更有规律。

wywy1995是其中最关键的一个人。他做了一件极其正确的事：把公式从股票移植到ETF，同时固定了一个只有4只ETF的"核心资产池"。

2.2 那个经典的25行代码

g.etf_pool = [
    '518880.XSHG',   # 黄金ETF
    '513100.XSHG',   # 纳指ETF
    '159915.XSHE',   # 创业板ETF
    '510180.XSHG',   # 上证180ETF
]
g.m_days = 25

def get_rank(etf_pool):
    score_list = []
    for etf in etf_pool:
        df = attribute_history(etf, g.m_days, '1d', ['close'])
        y = np.log(df.close)
        x = np.arange(len(y))
        # ★ 没有 w 参数，纯等权回归
        slope, intercept = np.polyfit(x, y, 1)
        annualized = math.pow(math.exp(slope), 250) - 1
        r_squared = 1 - (sum((y - (slope*x + intercept))**2) /
                         ((len(y)-1) * np.var(y, ddof=1)))
        score = annualized * r_squared
        score_list.append(score)
    # 取得分最高的那只，全仓买入

注意：这里没有任何权重。np.polyfit(x, y, 1) 默认全权重为1。这是纯粹的普通最小二乘法（OLS），每个数据点的权重完全相同。

统计学含义：OLS回归中，每个观测值对斜率估计的贡献完全相等。这意味着第1天和第25天的价格对趋势估计的影响是一样的。这是最"诚实"的估计方式——没有人为引入任何先验偏好。

2.3 前作：比代码更重要的东西

在写出策略代码之前，wywy1995还写了一篇更重要的文章——"从相关系数角度探讨ETF轮动的可行性"。

这篇文章的核心结论：

✅ 排除高度正相关（r>0.9）：沪深300与上证50成分股高度重合，轮动无意义

✅ 排除长期负相关：长期负相关的品种必然不断创新低，没有配置价值

✅ 选择中低相关（0.15~0.85）且基本面逻辑迥异的资产

他选出的四只ETF：

ETF 代表 宏观逻辑
518880.XSHG 黄金 避险/抗通胀
513100.XSHG 纳指 海外科技/成长
159915.XSHE 创业板 国内成长/小盘
510180.XSHG 上证180 国内价值/大盘

这四类资产分别对应经济周期中不同的风险敞口——它们的低相关性，是轮动策略能够持续产生超额收益的"土壤"。

📖 理论依据：这与Brinson, Hood & Beebower (1986)的经典资产配置研究一致——资产配置贡献了投资组合收益变异的90%以上。

代码是术，前作是道。真正有价值的，是通过相关系数论证"为什么这四类资产值得长期轮动"。

2.4 关于25日：一个必须正视的问题

《趋势永存》原书用的是90天动量。但wywy1995的策略里，g.m_days = 25。

为什么是25天？社区里有人做过测试：

参数 9年总收益
20日 208%
22日 446%
24日 729%
25日 836%
26日 887%
27日 742%
30日 550%

25日确实是一个局部最优解。但问题是：这个局部最优是"鲁棒的"还是"脆弱的"？

从数据来看，24日到26日，收益从729%到887%，波动158个百分点。不存在平稳区域——参数稍微一动，收益剧烈变化。这是过拟合的典型特征。

更深层的问题：克列诺原书使用90天（一个季度），背后有清晰的经济学逻辑——季度财报周期。而25天（约一个月）对应什么经济周期？没有明确的理论支撑。它更像是在A股市场的回测中被"找到"的。

CHAPTER 03

加权的出现——后续策略的"画蛇添足"

3.1 加权的代码

wywy1995的原始策略使用的是纯等权回归，没有任何权重。

而 np.linspace(1, 2, len(y)) 出现在：

• 五合一策略的策略一、策略二中

• 五福5.2的动量计算中

• 七星175的动量计算中

weights = np.linspace(1, 2, len(y))
slope, intercept = np.polyfit(x, y, 1, w=weights)

对于25天的数据，权重序列是：[1.0, 1.04, 1.08, ..., 2.0]

最旧的数据权重是1.0，最新的数据权重是2.0。旧数据的权重仍然是新数据的50%。

3.2 硬核分析一：有效样本量（ESS）

在统计学中，衡量加权回归"有效样本量"的指标是：

N_eff = (Σwᵢ)² / Σwᵢ²

这个公式来源于Kish (1965)的有效样本量理论，是抽样调查学中的经典工具。

对于25天、权重从1到2：

权重序列：wᵢ = 1 + (i-1)/24

Σwᵢ = 1.5 × 25 = 37.5

Σwᵢ² ≈ 58.51

N_eff = 37.5² / 58.51 ≈ 24.04

结论：等效等权样本量约为24天。

也就是说，在斜率的方差稳定性上，25日线性加权（1→2）几乎等同于24日等权回归。权重变化极其温和，几乎没有缩短有效样本量。

3.3 硬核分析二：边际影响力

从"最新一天价格对斜率的影响力"来看：

指标 线性加权(1→2) 等权(24天) 等权(19天)
最新数据权重占比 5.33% 4.17% 5.26%

最新数据的影响力约等于19天等权——这是线性加权实际产生的"近期偏好"程度。

3.4 硬核分析三：这个加权设计的问题

指标 数值 含义
等效样本量 24天 几乎等于等权
最新数据影响力 19天等权 近期偏好极其有限
最旧数据权重占比 2.67% 仍保有相当影响力
前10天总权重占比 ≈ 38% 近半权重来自10天前的旧数据

它两头不靠：

❌ 旧数据（前10天）仍占近40%权重，没有被有效衰减

❌ 新数据的影响力仅相当于19天等权，没有显著提升

❌ 等效样本量≈24天，几乎等于没加权

如果目标是"缩短周期"，直接使用15日等权更干净。如果目标是"强调近期"，指数衰减（半衰期8~12天）更有效。

线性加权（1→2）引入了额外的复杂度，却没有带来实质性的参数偏移。

3.5 替代方案的理论对比

方法 等效样本量 近期偏好 复杂度
等权（25天） 25 无 最低
线性加权（1→2） ≈24 微弱 中等
指数衰减（半衰期10天） ≈15 显著 中等
等权（15天） 15 无 最低

结论：如果想强调近期信息，指数衰减是更干净的选择。它的统计性质有明确的理论支撑——在信号处理中，指数衰减窗口对应于一阶IIR滤波器。

3.6 硬核分析四：R²计算中的统计错误

在五合一策略的策略一中，R²的计算：

# ❌ 错误写法
ss_tot = np.sum(weights * (y - np.mean(y)) ** 2)

对于加权回归，这是错误的。正确写法：

# ✅ 正确写法
y_weighted_mean = np.average(y, weights=weights)
ss_tot = np.sum(weights * (y - y_weighted_mean) ** 2)

这个错误表明，代码作者可能并未深入理解加权回归的统计学含义，只是沿用了社区流传的写法。

4.2 五合一的池子

璐璐202006的"五合一"策略，ETF池分为：

• 全球/海外ETF池：17只（大宗商品+海外ETF）

• 中国ETF池：约80只（港股+指数+行业）

• 合计近100只

问题一：Beta被稀释。

wywy1995的4只ETF代表的是宏观风险敞口（增长、通胀、避险、价值）。而100只ETF中包含大量行业ETF（半导体、酒、军工、光伏等），它们代表的是产业景气度，而非宏观风险敞口。

当黄金和半导体在同一个池子里竞争时，黄金的避险属性被稀释了——它现在要和半导体抢票，而不是作为一个独立的宏观对冲工具。

📖 理论依据：Ross (1976)的APT理论认为，资产收益由系统性风险因子驱动。4只ETF覆盖的是宏观因子（利率、通胀、增长），而100只ETF中大量行业ETF暴露的是行业特异性因子——后者不应成为轮动的依据。

问题二：过拟合空间指数级增长。

4只ETF的池子，参数优化的空间极其有限。100只ETF的池子，配合十几个参数，优化空间呈指数级增长。

6.2 核心创新：日内趋势确认

五福5.2最大的创新是日内趋势确认：

def check_intraday_trend(security, context):
    minute_data = get_price(security, count=30, frequency='1m', fields=['close'])
    closes = minute_data['close'].values
    closes = closes[closes > 0]
    if len(closes) < 5:
        return False
    x = np.arange(len(closes))
    slope = np.polyfit(x, closes, 1)[0]
    mean_price = closes.mean()
    slope_pct = slope / mean_price * 100  # ★ 归一化
    return slope_pct > 0.001  # ★ 阈值

亮点：斜率归一化。不同ETF价格量级不同，直接用斜率无法跨标的比较。通过除以平均价格再乘以100，转化为"每分钟涨跌幅百分比"，实现了可比性。

问题：阈值0.001是怎么来的？为什么不是0.0005或0.002？这个值大概率是在回测中调的。

买入流程：

13:10 —— 计算日线动量，确定目标列表。但不立即买入

检查最近30分钟趋势 —— 上涨则买入，下跌则等待

13:40、14:10、14:40 —— 三次复检

14:55 —— 强制买入所有剩余目标

逻辑是自洽的：日线动量告诉你"买什么"，分钟趋势告诉你"什么时候买"。

7.2 滤波器切换

拉普拉斯滤波器（正常期）：指数平滑，响应快，适合趋势跟踪。

def laplace_filter(price, s=0.05):
    alpha = 1 - np.exp(-s)
    L = np.zeros(len(price))
    L[0] = price[0]
    for t in range(1, len(price)):
        L[t] = alpha * price[t] + (1 - alpha) * L[t - 1]
    return L

高斯滤波器（震荡期）：权重呈钟形分布，对最近价格变化不敏感，适合过滤震荡噪音。

def gaussian_filter_last_two(price, sigma=1.2):
    n = len(price)
    idx = np.arange(n)
    weights = np.exp(-((idx + 1) ** 2) / (2 * sigma ** 2))[::-1]
    weights /= np.sum(weights)
    g1 = np.sum(price * weights)
    g2 = np.sum(price[:-1] * weights[:-1])
    return g1, g2

逻辑自洽：趋势行情用拉普拉斯（快），震荡行情用高斯（稳）。

理论依据：拉普拉斯滤波器本质上是指数加权移动平均（EWMA），在金融时间序列分析中广泛使用（Tsay, 2010）。高斯滤波器则是经典的低通滤波器（Oppenheim & Schafer, 2010）。

7.3 参数统计

七星175至少17个可调参数：

A股弱（7指数、10日均线、4/7阈值）· 海外弱（4代理、10日均线、2/4阈值）· 纳指空仓（振幅3%、6日）· 震荡期（乖离率10%、RSI超买75、回落60）· 滤波器（拉普拉斯s=0.05、高斯σ=1.2）· R²过滤（0.35/0.32）· 其他（盈利保护5%、买入下限0.20）

CHAPTER 08

批判——哪里有问题？

8.1 25日参数：过拟合的典型

从20日到30日，收益从208%到887%再到550%，波动极大。不存在平稳区域。一个具有经济学含义的参数，应该在合理范围内表现相对稳定。25日显然不满足这个条件。

结论：25日很可能是一个过拟合的参数。

8.2 线性权重（1→2）：低效的"创新"

等效样本量≈24天，几乎等于等权。最新数据影响力≈19天等权，近期偏好极其有限。前10天仍占近40%权重，旧数据没有被有效衰减。

结论：引入了额外的复杂度，却没有带来实质性的参数偏移。

8.3 池子膨胀：Beta被稀释

从4只到100只，池子扩大了25倍。宏观风险敞口被产业景气度稀释，过拟合空间指数级增长，交易成本上升。

结论：池子膨胀是过拟合的重要来源。

8.4 五合一的逻辑撕裂

策略一/二（绝对动量）和策略三/四（相对动量）混在一起投票，在熊市中会导致错误开仓。

结论：集成不能掩盖子策略的逻辑缺陷。

8.5 参数爆炸

五福至少11个可调参数，七星至少17个。17个参数，每个3-5个取值，组合空间是天文数字。

结论：参数越多，过拟合风险越高。

📖 Harvey, Liu & Zhu (2016) 的警示：由于多重假设检验问题，金融学中许多"显著"的因子可能是假阳性。对于17个参数的策略，t统计量需要远高于传统的2.0才能被认为是真实的。

9.3 如果你要使用这些策略

第一，回到wywy1995的原始版本。

4只ETF、等权回归、25日动量。它不够性感，但足够透明。你知道它在算什么，你知道每个参数为什么是这个值。

第二，如果非要加权，用指数衰减。

# ✅ 用这个（半衰期10天）
halflife = 10
weights = np.exp(-np.arange(len(y)) / halflife)

第三，做参数敏感性测试。

把核心参数在合理范围内变动，观察策略表现是否剧烈变化。如果参数稍微一动收益就大幅下降，那策略是过拟合的。

第四，做样本外测试。

用2015-2020年数据训练，2021-2026年数据测试。如果训练集上表现极好、测试集上表现极差，那就是过拟合。

第五，降低杠杆。

回测曲线陡峭意味着波动也大。建议降低仓位。

第六，不要迷信回测曲线。

回测是策略的"简历"，实盘才是策略的"面试"。简历可以润色，面试骗不了人。

一条公式，从一本英文书出发，经过至少五个人的手，演化成了两个截然不同的策略。

能用的核心原因：底层因子有20年实盘背书。

不能盲目用的核心原因：在这个可靠因子的基础上，叠加了太多"在回测中调出来的"参数和条件。池子从4只膨胀到100只，参数从0个增加到17个以上。

如果你能剥离那些过拟合的"装饰"，只保留核心的动量因子和合理的风控逻辑——那它们是有用的。如果你原封不动地拿去实盘——回测如画，实盘拉胯。

1. 25日参数很可能过拟合了——从20到30，收益波动极大，不存在平稳区域。

2. 线性权重（1→2）是低效的"创新"——等效样本量≈24天，几乎等于没加权。
